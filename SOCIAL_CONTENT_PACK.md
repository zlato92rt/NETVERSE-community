## Reddit technical discussion

Title: We are building consent-based Android compute where uptime alone earns nothing — looking for architecture feedback

We are building NETVERSE, a Web + Android platform combining paid AI services, creator commerce and opt-in distributed compute.

One design choice we made early: heartbeat/online status is not treated as paid work.

The path we are validating is:
1. explicit device consent;
2. authenticated device identity;
3. bounded workload delivery;
4. local execution;
5. signed result submission;
6. independent server validation;
7. accounting only after valid work.

The first workload is deterministic SHA-256 batching because we want to prove the control plane before broader compute.

We would especially value feedback on anti-replay, job validation, contributor trust and safe workload expansion.

https://github.com/zlato92rt/NETVERSE-community
