# Security Policy

## Reporting a vulnerability

Please do **not** publish vulnerabilities, exploit details, credentials or security-sensitive information in a public issue.

Use GitHub private vulnerability reporting when it is enabled for this repository. If it is unavailable, contact the NETVERSE team through an official channel and include:

- A clear description of the issue
- Reproduction steps
- Potential impact
- Any proposed mitigation

## Scope

Reports concerning the public community materials are welcome. Production infrastructure, payment security, node credentials and private backend services remain outside the public repository.

We will acknowledge valid reports and investigate them responsibly. No reward or payout is promised unless a separate written program explicitly states otherwise.
